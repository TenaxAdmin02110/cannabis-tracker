# National Cannabis Outlook Tracker: client site

The standalone, client-facing copy of Tenax Strategies' National Cannabis Outlook Tracker, served by GitHub Pages at `https://tracker.tenaxstrategies.com`.

The tracker itself is maintained in Claude. This repository holds its published page and data, which the daily refresh updates.

See [HANDOFF.md](HANDOFF.md) for how the site works and how to publish to it.
